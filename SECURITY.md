# Security

Supported version: the default branch of this repository.

If you believe you have found a security vulnerability, please email hello@galaxia.help. Please do not open a public GitHub issue for security reports.

This repository does not offer a bug bounty.

If this repository contains a user-facing dApp, it is intended for testnet / Sepolia use unless the README states otherwise. Do not assume mainnet support.

This file does not claim that the software has been audited or certified.
